# adamhemmouda.com

Personal portfolio for Adam Hemmouda, published with GitHub Pages.

The site is a dependency-free static web app with responsive layouts, an installable web manifest, offline caching, and a public-safe downloadable resume. Projects, experience, and skills each have a dedicated route under the primary domain.

## Typography

The site and public resume use Liberation Sans 2.1.5 from the official Liberation Fonts project. The font files are redistributed under the SIL Open Font License 1.1; the required notice and complete license are included at `assets/fonts/LICENSE-Liberation-Sans.txt`.

## Local preview

Serve the repository root with any static HTTP server, then open the local URL in a browser.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. Keep the `CNAME` file in place so the custom domain remains connected.
